# 两站样式规定（移交版）

> 来源：原网站维护者移交，Kyle 于 2026-11-17 转交 Muse 存档。适用于 rouguang-site 与 rouguang-video 两站的一切改动。

## 一、视觉基调
- 背景：#0c0c0d 暗夜黑（全站唯一底色）
- 文字：暖白 #e8e6e1，次级 #b9b6b0 / #8a8681
- 线条：发丝级 rgba(232,230,225,.07~.32)，1px 封顶
- 字体：衬线为主（宋体/游明朝/Noto Serif，音乐区 EB Garamond）；数字与标签用等宽（IBM Plex Mono）
- 铁律：禁用斜体；胶片颗粒 ≤4%；元素宁少勿挤；删内容也留白

## 二、装裱与版式（数据已钉死）
- 图片/视频一律 contain 装裱，绝不裁切（横竖版完整呈现，视频竖版两侧留黑边）
- 艺术工作室卡片：相册视图 上40px / 下76px；网格视图 上25px / 下51px
- 序号 01-03 嵌在双框之间右对齐；照片 空 meta = 留白（不挂名牌）
- 任何比例改动必须逐次报实测像素

## 三、动效
- 只动 transform / opacity，≤300ms，cubic-bezier(.23,1,.32,1) ease-out
- 展开 = 一次性全到位（去错峰，11-17 定案）
- 三件套（cult-ui DNA）：hover 内框微抬 4px / 按压 scale(.96) / 灯箱共享元素原位飞入放大
- prefers-reduced-motion 下全部关断；无目的光效（AI-glow）禁用；品牌焦点环与 ::selection 保留

## 四、交互结构
- 收起按钮（2026-11-18 Kyle 改定，替代下方居中）：展开后在左上角，玻璃质感，sticky 跟随页面滚动、不超出本相册/频道上下边界；分组自治（哪本相册的按钮跟哪本走）；Music 分组恒显「收起专辑」
- 语境措辞三态（中日英联动）：照片=相册 / 音乐=专辑 / 视频=频道；EN 的 album 两义通用不翻
- 灯箱：点击卡片飞入展开，ESC / 点背景关闭；三语切换 + localStorage 记忆

## 五、文案排版
- 诗行独立、句子不腰斩、标点让位换行（自述诗体是定稿）
- 三语各自成段，EN 态自动隐藏重复副标

## 六、卡套（2026-11-18 新增，Kyle 定案；v2 按 demo 1:1 复刻）
- 相册/视频频道入口套一层横向卡套，卡片本体与版式数据一条不动：卡套只是相册/频道容器这一层的外壳，悬停时整叠卡向右横抽 34px（两站同），打开相册/频道或切网格视图时卡套自动隐藏；动效 ≤300ms、cubic-bezier(.23,1,.32,1)；prefers-reduced-motion 下关断
- 参数（以卡宽 cardW 为基准，两站一致，源自 demo 定稿；2026-11-18 主站缩小版）：卡套总宽 1.6×cardW（此前 1.923×，Kyle 嫌太大、挡下方提示），套身宽 0.96×cardW，卡片探出仍约 52%；套身高 cardW + 125px（贴合 3 张叠卡，底边比叠摞底多 20px；2026-11-18 曾统一为 Loose 的长条 cardW + 174px，后因叠摞只留 3 张而改小；再之前套身高跟随各自叠摞）；闭合态容器高 cardW + 180px，提示统一落在套身下约 17px；展开态仍按叠摞 maxBottom + 64px；圆角 0.0867×cardW（cardW 330 时约 29px）；右侧开口为圆润拇指凹口（demo 原 clip-path 多边形，2026-11-19 改浅：最深处在套身宽 96%、高 50% 处，此前 91.2%；因照片从缺口露出形成亮条，Kyle 同意改浅，卡面不动；两站同步）；无装饰圆点。视频站套身 2026-11-18 晚改小到与主站一致：套身宽 0.96×cardW、位移 −0.25×cardW，闭合卡宽封顶 213、下限 154（主站闭合封顶 242；视频站相册列更窄，公式顶到 242 会偏大，遂把上限压到 213，与主站闭合卡宽一致）；高仍 calc(100% − 56px)（16:9 叠摞适配）。闭合叠摞只显示前 3 张（2026-11-18 Kyle 定：超过 3 张也不全展示，统一 3 张叠在一起的效果；多余的卡片闭合时 display:none，展开/网格视图时恢复全部显示）；视频站同样只留 3 张，闭合容器按 3 张叠卡取齐，两个频道卡套同高
- 套身材质（亮面，无纹理）：底渐变 105deg（2026-11-18 改半透明：rgba(42,42,47,.88) → rgba(20,20,22,.86) → rgba(6,6,7,.90)，透出一点里面明信片的颜色），叠向右加深的 shade（.04→.22→.45）与两层 gloss 高光，内侧 1px 高光边；2026-11-19 Kyle 选皮革纹装饰，套身最上层加了一层 SVG 颗粒（feTurbulence fractalNoise，baseFrequency 0.28，灰度，透明度 0.08，平铺 180px）；2026-11-24 Kyle 嫌纹理不好看，已整层移除，亮面与高光层不动；套身在卡片上投阴影（主站 box-shadow 32px 0 48px rgba(0,0,0,.40)，视频站 drop-shadow 等效）。2026-11-19 注：曾短暂改为哑面（删 gloss），Kyle 纠正为卡面保持亮面原样、只去缺口处高光，已恢复；查证亮条是照片从缺口里露出来（缺口处照片亮度约 40、卡套约 12），不是高光层，2026-11-19 Kyle 同意把缺口改浅（最深处 91.2%→96%），已实施，两站同步。
- 探出：明信片再往里塞 1/4 卡宽后，探出约 27%（此前 52%；两站套身位移均为 −0.25×cardW）
- 排版（2026-11-18 Kyle 要求一行两个）：#works 为 2 列网格（主站 ≥700px 视口、视频站 ≥1024px 视口；窄屏回单列）；sec-label、工具栏、空态占满整行；展开的相册/频道占满整行（.span-all，JS 在 toggle 与视图切换时同步，网格视图下全部占满整行）；视频站纪录片单元已删，现只剩短视频与专题片，正好一行两个
- 卡片尺寸（2026-11-18）：主站卡宽公式整体 ×0.832（卡套 1.923→1.6 的同比例），封顶 330→275、下限 210→175，内部比例（序号行、内框、留白）严格不变；后为治溢出再 ×0.88，封顶 242、下限 154。2026-11-18 晚起卡宽随状态变化：闭合态用小卡宽配小卡套（主站封顶 242、下限 154；视频站封顶 213、下限 154），展开后恢复改小前的尺寸（主站封顶 330、下限 210；视频站封顶 360、下限 230）；展开网格的卡片在格内居中，仍占满整行；网格视图的卡片尺寸由网格本身决定，不受此影响
- 套身文字（点睛之笔）：左上角数量徽标（苹果风磨砂玻璃：半透明底 rgba(255,255,255,.14)、backdrop blur 12px + saturate 1.4、细白边、字号比初版小一号），左下角只写相册名（Observation / Loose / Music），左 7.5%、上下各留 9%、宽不超 72%；标题字号 0.0736×cardW、700、字距 .14em（中文小字已删：海岸 · 观察、城市 · 雨夜、平行的风都不是相册名）。主站：上方原标题已删（Observation、Loose 的 .album-title 已移除，Music 的保留）；左上角徽标现为内容物数量（JS 从各相册的 .work 数生成：Observation 3张、Loose 16张、Music 1首），所有分类下都显示（此前写「照片」/「流行」且只在「全部」下显示，2026-11-18 改为数量常显）。视频站：分类标题已在画册上方，卡套左下角只写子标题——短视频「近期」、专题片「早些」（JS 生成）；左上角条数徽标量词统一为「条」（▶12 条 / ▶2 条，2026-11-18 晚统一，此前专题片写「部」），JS 从 videos.length 取；纪录片单元已删（空频道）
- 工具栏按钮（2026-11-18）：6 个 pill（全部 / 照片 / 视频 / 音乐 / 相册 / 网格）与套身徽标同款苹果玻璃（半透明底 rgba(255,255,255,.14)、backdrop blur 12px + saturate 1.4、细白边、柔和阴影；悬停底 .20、边 .5；选中态底 .24、边 .6、字纯白）
- 收起按钮（2026-11-18 Kyle 改定，两站同款，核查全过：主站 ?v=34、视频站 ?v=37）：展开后在各组左上角（主站为组内第一个子元素，视频站为标题下方、.works 之前），苹果玻璃（与徽标、工具栏同款），position:sticky（主站 top 96px、视频站 top 80px，均避开顶部固定导航），z-index 70（盖过卡套 z-index 60）；滚动时跟随，不得超出本相册/频道上下边界；滚过底部时淡出隐藏（opacity 0、.past 类，IntersectionObserver 触发，滚回来重新出现）。触发条件两站不同：主站为组底滚过悬停线（136px）；视频站为组在视口内可见不足 40%——视频站页面下方内容太短，像素触发线滚到底也碰不到（曾因此两次修补未生效：body overflow-x:hidden 改 clip 无效；像素线改比例触发后才通过）。展开时 JS 给组加 .open，切网格视图时同步去掉；收起按钮点击改按所属组查找相册。另：Music 套身下补「专辑 · 点击展开」提示（中/英/日三语，专辑措辞与收起专辑一致）
- 主站用法：每本相册 `.works[data-album]` 容器末行（album-hint 之后）加 `<div class="album-sleeve-front" aria-hidden="true"></div>` 一行即可，CSS（`.album-sleeve-front`）已在页面 `<style>` 里、跨相册共用；往现有相册加照片按老办法，不用动卡套
- 视频站：卡套是 `.works::after` 伪元素（容器由 JS 生成卡片，故不用 div），CSS 在页面 `<style>` 里；加新视频、新建频道都不用管，自动生效
- 版本锚点：卡套改动之前的版本为「正式版 1.1」（site e8a05d4 / video 07f4dd1），随时可回滚；视频站另修了一个旧 bug：「点击展开」提示的选择器层级（.album-hint 是 .works 的兄弟元素，应为 `+` 而非后代选择器）

## 七、日间模式（2026-11-19 Kyle 定案：亮版主题，卡套保持深色）
- 切换：顶部导航语言切换旁加太阳/月亮按钮（☀/☾），点一下在日间（亮版）与夜间（深色）之间切换；深色态按钮显示 ☀（点一下变日间），亮版态显示 ☾（点一下回夜间）；选择记 localStorage（主站 rg-theme、视频站 site-theme），默认夜间（深色，即原配色），刷新不丢；<head> 里有防闪烁小脚本（先读 localStorage 再上色）
- 亮版配色（暖纸白，与夜间暖调呼应）：页面底 #f4f1ea，文字暖炭黑 #1e1c19，次级暖灰 #8a8478，细线 rgba(30,28,25,.14)；卡片底 #fbf9f4、相框底 #ece8df；视频站 --mid #6f6a5e、--hair rgba(30,28,25,.14)、--hair2 rgba(30,28,25,.08)
- 卡套保持深色不变（Kyle 定案）：亮版下页面变亮，深色卡套更突出；亮面、缺口、徽标、标签全部不动（皮革纹已于 2026-11-24 移除），徽标与标签仍为白色（在深色卡套上）
- 灯箱保持深色（两站同）：看照片深底更好；亮版下灯箱内文字、边框、按钮仍用浅色
- 工具栏 pill 与收起按钮（玻璃质感）在亮版下改深色玻璃：底 rgba(30,28,25,.06)、边 rgba(30,28,25,.20)、字 rgba(30,28,25,.80)；悬停底 .10、边 .45；选中态底 .12、边 .45、字 #1e1c19
- 实现：`html[data-theme="light"]` 覆盖 :root 变量 + 针对性覆盖（卡片、相框、提示、按钮、选中、滚动条等）；深色为默认 :root 值，无需覆盖
- 明信片保持原色（2026-11-19 Kyle 定）：亮版下明信片（卡片与相框）仍为原色深色（卡底 #0f0f10、框底 #121213、卡上文字与边框仍用浅色），只变页面底色与页面文字；深色明信片衬在暖纸白页面上
- 视频站页眉：语言切换与主题按钮包在一个 .hbar-right 里（flex），语言切换回到右端原位（此前因 space-between 三子元素被挤到中间，Kyle 指出后修复）
- 收起按钮亮版改实色浅底（2026-11-19 核查发现）：亮版下收起按钮在展开的深色卡片上对比不足（半透明深底 + 深字），改为实色浅底 rgba(244,241,234,.88)、深字 #1e1c19，悬停 .95；两站同
- 视频站页眉渐变（2026-11-19 核查发现）：固定页眉的深色渐变（rgba(12,12,13,.92)→透明）在亮版下仍为深色，语言切换与 ☾ 显灰；亮版下改为浅色渐变 rgba(244,241,234,.92)→透明；主站页眉用 mix-blend-mode:difference 自适应，无需改
